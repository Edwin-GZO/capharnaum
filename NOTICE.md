# Crédits et provenance

Cette adaptation reprend l'interface et les données du créateur de personnages
Capharnaüm réalisé par **tut-tuuut** :

- Site original : https://tut-tuuut.github.io/capharnaum-character-creator/
- Dépôt original : https://github.com/tut-tuuut/capharnaum-character-creator

Le fichier `assets/fiche-personnage-v10ans.pdf` est le modèle de feuille de
personnage fourni pour ce projet. Les droits sur Capharnaüm, ses textes, son
univers et ses éléments graphiques restent la propriété de leurs ayants droit.

Les ajouts de ce dépôt comprennent notamment l'API Node.js, la génération
aléatoire, la validation des personnages et le remplissage du modèle PDF.
